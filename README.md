# Car CO2 Emissions Prediction

## 🌍 Overview
This project predicts CO2 emissions of vehicles based on features like engine size, fuel consumption, and vehicle class. Multiple regression models are used to evaluate performance and accuracy.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## 📁 Files
- `co2_emission_prediction.ipynb`: Main notebook with data preprocessing, model training, and evaluation
- `README.md`: Project summary and instructions

## 🚀 How to Run
1. Clone the repo
2. Install dependencies: `pip install pandas matplotlib seaborn scikit-learn`
3. Open `co2_emission_prediction.ipynb` in Jupyter Notebook
4. Run cells sequentially to view predictions and model comparisons

## 📌 Use Case
Useful for environmental analytics, automobile industry insights, and government policy modeling related to vehicle emissions.
